# 発見

高専祭の受付で提示するQRコードのリンク先。開くと「発見」の文字、紙吹雪、発見済スタンプが出て、感謝のメッセージが残ります。照合・入力・登録はありません。

HTML / CSS / JavaScriptのみ。ビルド・外部ライブラリ・外部フォント・通信APIは不要です。元のポスター `docs/image.png` を残し、表示には軽量化した `docs/poster.jpg` を使います。

## GitHub Pagesで公開

1. このフォルダーの内容をGitHubリポジトリにpushします。
2. リポジトリの **Settings → Pages → Build and deployment** で **Deploy from a branch** を選びます。
3. 公開するブランチと **/ (root)** を選び、**Save** を押します。`/docs` は画像の保管先なので、公開元に選ばないでください。
4. 発行された `https://ユーザー名.github.io/リポジトリ名/` をQRコードにして受付に掲示します。

サイトは相対パスだけで構成しているため、リポジトリ名の付くURLでも動作します。公開URLがまだないため、QR画像自体は同梱していません。

## 動作

- QRからページを開くだけで演出が始まります。
- 初回は音なしです。スマホの自動再生制限に対応し、右上の「音を出す」を押すと音ありで演出を再生します。
- 「もう一回」で演出を再生できます。ページを読み込み直しても再生します。
- OSの「視差効果を減らす」などの設定時は、動きと紙吹雪を止めて完成画面を表示します。
- カメラ・個人情報・位置情報は使いません。

## 手元で確認

このフォルダーで `python -m http.server 8000` を実行し、`http://localhost:8000` を開きます。`index.html` を直接開いても動作します。

画面の文言は `index.html`、配色や動きは `style.css`、紙吹雪や音は `script.js` で変更できます。
